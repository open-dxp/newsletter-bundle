# OpenDXP Newsletter Bundle
This bundle provides a basic newsletter framework with the advantage to use all the data that is already stored in the system.

## Features in a Nutshell 
- Add a basic newsletter functionality to OpenDXP.
- Add a new OpenDXP-specific Document type to create newsletters with OpenDXP Documents (and all related concepts and features).
- Send newsletters directly from OpenDXP Admin UI.
- Provide support for setting up a subscribe/confirm/unsubscribe workflow.
